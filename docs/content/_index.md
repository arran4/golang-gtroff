# gtroff

> **Work in progress.** This is public-facing development documentation, not a stable release or a promise of complete GNU groff compatibility.

A pure-Go toolkit for inspecting roff/man syntax, navigating a source-aware AST, validating documents, and rendering or converting a documented subset of Linux manual pages.

Browse the [reference documentation](docs/reference/) or read the [source README](https://github.com/arran4/golang-gtroff#readme).

The online site is generated from the maintained Markdown under `docs/*.md`, not a second independently edited copy. Capabilities shown here depend on which changes have reached `main`; see the [open pull requests](https://github.com/arran4/golang-gtroff/pulls) for work still in review.

# gtroff

A pure-Go toolkit for reading, querying, analysing and rendering roff and Linux man pages.

- [Go API examples](docs/reference/go-api/) — embed source-aware parsing and semantic inspection.
- [Library guide](docs/reference/library/) — tokens, documents and optional evaluation.
- [Getting started](docs/reference/getting-started/) — build the CLI and process a first manual page.
- [CLI workflows](docs/reference/workflows/) — inspect, query, extract and render.
- [Compatibility](docs/reference/compatibility/) — supported features and limitations.
- [Full reference](docs/reference/) — detailed API and command guides.

gtroff supports a subset of roff and is under active development. It is not a complete GNU groff replacement.

[Source and examples on GitHub](https://github.com/arran4/golang-gtroff)

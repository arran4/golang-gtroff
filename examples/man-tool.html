MAN-TOOL(1)

User Commands · Linux · 2026-10-21

NAME#

man-tool - inspect a source document

SYNOPSIS#

man-tool [-v] [-o file] input

DESCRIPTION#

Read input and inspect its structure.

Output preserves the original source independently of canonical text.

Input formats#

The first implementation handles typical Linux man pages.

OPTIONS#

-v

Display verbose diagnostics on standard error.

-o file

Write the selected document to file.

•

No automatic includes or external commands.

Indented explanatory text.

EXAMPLES#

  man-tool -v input.1
  man-tool -o output.txt input.1
